## Story

**As a** technical visitor, **I want** to manipulate a safe drum transcription in the browser, **so that** I can evaluate DrumAI without installing models or using copyrighted music.

## Acceptance Criteria

1. A static demo plays an original synthesized drum loop and displays a precomputed chart.
2. Tempo, metronome, loop, bar editing, arrangement, and export controls work without a backend.
3. The page distinguishes the working private CPU pipeline from the public deterministic demo.
4. No copyrighted recording, lyrics, credentials, proprietary source, or network write is present.
5. README, tests, Pages workflow, license boundaries, and responsive WCAG AA behavior are complete.
